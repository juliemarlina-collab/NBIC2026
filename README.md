# NBIC 2026 Website

GitHub-ready static website package for the National Biz-Inno Challenge 2026.

## Folder structure

- `index.html` — homepage
- `css/styles.css` — website styling
- `js/script.js` — navigation and animations
- `assets/images/nbic-logo.jpg` — official NBIC logo supplied
- `assets/images/nbic-hero-header-main.png` — electric-blue metallic liquid hero background
- `assets/images/polipd-logo.png` — placeholder location for Politeknik Port Dickson logo
- `assets/images/kptm-logo.png` — placeholder location for ministry/organiser logo

## GitHub Pages

1. Upload all files and folders to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/root` folder.
5. Save and wait for the published link.

## Adding organiser logos

Place the final logo files inside `assets/images/` using these names:

- `polipd-logo.png`
- `kptm-logo.png`

The organiser logo area can be inserted into the header or hero after the files are supplied.
